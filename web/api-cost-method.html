API 成本估算方法

把已记录的模型用量换算到统一的 API 价格口径，分别展示实测缓存下的价格参考区间，以及全部输入按缓存价计费的乐观下界。

价格核对：2026-10-21 · 单位：美元 / 已发布结果样本 · Standard API 价格

两项指标都是估算，不代表 Codex 订阅账单、账号额度消耗或真实扣款。

两个指标价格与长度参考区间乐观下界范围与证据论文表述官方来源

两个指标，使用相同的样本范围

指标 01

实测缓存 API 均价

沿用已记录的输入、输出和实际缓存命中量。缓存写入量未保存，因此给出普通输入价至30分钟写入价的参考区间。

是实测用量的API价格重估，不是已核对的实际账单。

指标 02

全缓存乐观下界

把全部输入按缓存读取价计费，输出仍按输出价计费；忽略首次输入、新增输入和写入缓存的额外成本。

不代表所有输入真的可缓存，也不等于“所有可缓存输入都命中”。

两者只改变价格假设，不改变模型调用次数、实验结果或原始 token 记录。

指标一：实测缓存 API 均价

对每条可归属的用量记录 j，总输入为 Ij，实际缓存读取为 Cj，输出为 Oj，未命中部分为 Uj = Ij − Cj。缓存读取属于输入，不再额外加到输入上。

完整输入费用需要区分普通输入、缓存读取和缓存写入；写入与读取不重叠。当前公开历史记录没有保存足够的 cache_write_tokens，因此不虚构写入量。30分钟写入单价为普通输入价的1.25倍。官方缓存计费说明

参考下端 Lj = (Uj × pI + Cj × pC + Oj × pO) / 1,000,000
参考上端 Hj = (Uj × pW + Cj × pC + Oj × pO) / 1,000,000
平均参考区间 = [Σ Lj / N, Σ Hj / N]

下端把未命中部分全部按普通输入价计算；上端把它全部按30分钟写入价计算。同一token不会同时收取这里的普通输入费和写入费。每条记录先应用对应模型与请求长度的单价，再汇总。

若一条累计记录包含多个模型响应，累计输入超过272,000，却缺少逐请求分配，不能断言每次请求都进入长上下文档位。此时保留“全部按短请求价”至“全部按长请求价”的保守包络，并提示长度归属不确定。累计输入不超过阈值时，其中各请求也不会超过阈值。

有未知usage时，区间只针对已知部分。右端不是整个实验实际费用的上界，未知usage不按零补齐。缓存数或输入/输出拆分无法确定时，保留缺失提示，不用总token数猜测费用分区。

指标二：全缓存乐观下界

乐观费用 Bj = (Ij × pC + Oj × pO) / 1,000,000
平均乐观下界 = Σ Bj / N

全部输入都假设按缓存读取价计费，忽略首次请求、新增输入和缓存写入的额外费用。已知长请求仍使用长上下文倍率；请求长度归属无法判定时，为保持乐观下界采用短请求价。有未知usage时，只累计已知部分。

实际缓存命中量不等于理论可缓存量。实际命中还受请求前缀、路由、时间间隔等影响；首次输入和新增内容也不能仅凭累计usage判为可复用。本指标不从实际Cj推断可缓存前缀，是一种统一、偏乐观的参照，不是优化后必然能够达到的开销。

范围、分母与证据

  • N是已发布结果样本数。在当前范围内去重后计算每个样本的算术平均；不是每次API调用均价，也不是任务或能力宏平均。空范围显示“—”。
  • 不按计划总数摊薄。发布1例就除以1，不除以42或111。未完成首轮、Spiky-2或P50_111时不外推全套费用；实验卡片的当前范围也不自动等同固定评测范围。
  • 重试和失败留在分子。包含已记录且归属于该范围的尝试，但不增加结果样本分母。LOW的两个额外无效尝试计费、不参与评分、不增加N，只归属相应范围，不重复加入其他轮次。
  • 模型分别计价。Astra与Luna使用各自单价。多个模型参与同一episode时按已知模型身份分别计算；未知或未映射模型不静默套价。
  • 观察和控制都计入。Generation记录已包含观察模型与控制模型的尝试，不能再次追加一遍观察费用。
  • 声明用量保留证据标记。已接受补件的声明usage可用于估算，但注明“含补件声明用量”。accounting=known不等于收据身份已验证。
  • 未知成本保持未知。不把缺失值当成零；已知部分的参考区间不是完整账单的置信区间。

论文可复用表述

以下段落可复制到方法或成本分析部分；引用时保留核价日期和未知用量边界。

为在统一价格口径下比较推理开销，我们根据已发布结果中的输入、输出及缓存读取token计数，采用2026年10月21日核对的OpenAI Standard API单价，报告两种按结果样本数计算的算术平均成本。第一种为实测缓存API价格参考区间：保留已记录的缓存读取量，将未命中输入分别按普通输入价和30分钟缓存写入价计费，以反映未保存缓存写入计数造成的不确定性；对无法由累计usage确定的长上下文请求归属，进一步保留短、长请求价格包络。第二种为全缓存乐观下界：假设全部输入按缓存读取价计费，输出按输出价计费，忽略首次输入、新增输入及缓存写入的额外开销。该下界不声称所有输入均可缓存，也不以实际缓存命中量替代理论可复用前缀量。成本分子包含范围内已记录的重试和无效尝试，分母仅计已发布的结果样本；这不是能力宏平均，也不对未完成的固定评测集合外推。存在未知usage时仅报告已知部分，参考区间的右端不构成完整实验成本上界；补件声明用量保留其证据标记。这些数值是公开API价格下的估算，不是Codex账单或账号额度度量，也不包含12小时缓存、特殊速度档位、税、工具、GPU或仿真费用。
